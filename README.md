## Overview

This repository contains the artifacts for the **SIH2026 Telemedicine Screening** project. The project focuses on automated detection and reporting of diabetic retinopathy using deep‑learning models and Simulink workflows.

## Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/hk3202/SIH2026-Project.git
   cd SIH2026-Project
   ```
2. **Set up the environment**
   - Install MATLAB/Octave.
   - Ensure Simulink is available for the workflow file.
3. **Load the models**
   ```matlab
   % Add the models folder to the MATLAB path
   addpath(fullfile(pwd, 'models'));
   % Load a model (example)
   load('dr_resnet50_model.mat');
   ```
4. **Run the Simulink workflow**
   ```matlab
   open('simulink/telemedicine_screening_workflow.slx');
   set_param('telemedicine_screening_workflow', 'SimulationCommand', 'start');
   ```
5. **View generated reports**
   ```bash
   start reports/DR_Report_sample_fundus_20260909_071949.pdf
   ```

## Usage Details

- **Models** – The `.mat` files in `models/` can be loaded directly in MATLAB/Octave. They contain pretrained ResNet‑50 and U‑Net networks for disease classification and exudate segmentation respectively.
- **Simulink Workflow** – Open `simulink/telemedicine_screening_workflow.slx` in Simulink to execute the full screening pipeline. The workflow reads image data, runs inference using the models, and outputs a PDF report.
- **Reports** – PDF files are stored in `reports/`. Each report corresponds to a processed fundus image and includes diagnostic metrics.
- **Assets** – Image assets (e.g., `training.png`) reside in `assets/images/` and can be used for documentation or UI mock‑ups.
